# Viva Questions and Answers

1. **What is sales forecasting?**  
   Estimating future sales using historical data and relevant factors.

2. **What is predictive analytics?**  
   Using data and analytical methods to estimate likely future outcomes.

3. **Which algorithm is used?**  
   Random Forest Regression.

4. **Why is this a regression problem?**  
   The target, sales, is a continuous numerical value.

5. **What is Random Forest?**  
   An ensemble method that combines predictions from multiple decision trees.

6. **What is feature engineering?**  
   Creating useful model inputs from raw data.

7. **What is a lag feature?**  
   A previous period's sales value used as an input.

8. **What is a rolling mean?**  
   The average of values across a moving time window.

9. **Why use chronological splitting?**  
   It prevents training on future observations when testing on earlier observations.

10. **What is MAE?**  
    The average absolute difference between actual and predicted values.

11. **What is RMSE?**  
    The square root of mean squared prediction error; larger errors receive more weight.

12. **What is R²?**  
    A measure of the proportion of target variation explained by the model.

13. **Why use Streamlit?**  
    It quickly creates interactive Python data applications.

14. **Why is CSV upload useful?**  
    It allows users to test the model on their own sales data without editing the source code.

15. **What columns are required?**  
    Date and Sales.

16. **What is the minimum dataset size?**  
    The app requires at least 15 monthly records; more data is recommended.

17. **What are the limitations?**  
    Small or unrepresentative datasets, unusual events, and recursive forecast errors can reduce accuracy.

18. **How can the project be improved?**  
    Add real business data, holidays, promotions, product categories, and compare several forecasting algorithms.
